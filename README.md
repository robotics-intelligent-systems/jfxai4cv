# Artificial Intelligence in Medical Imaging

Musculoskeletal Atlas Project (MAP) is an open-source software framework that provides an easy-to-use application for visualising imaging data, segmenting images, creating geometric meshes, and exporting OpenSim and FE models. Surgical Planning is a custom 3D Slicer extension made up of 2 modules, both focused on planning a surgical path. Open Framework for Federated Learning. Ultralytics creates cutting-edge, state-of-the-art (SOTA) YOLO models. Open Source Biometrics, Face Recognition. Open-source automatic fingerprint identification system (AFIS). Kryo is a fast and efficient binary object graph serialization framework. Apache Flink is an open source stream processing framework. The BRIAR Application Programming Interface (API). NIST Biometric Image Software. Biometric SDK is complete open-source Software Development Kit for face, iris and fingerprint modalities. Creating a 3D Graph Neural Network (GNN) involves using libraries and frameworks that support graph-based machine learning and 3D visualization. One such library is JGNN. JavaCV uses wrappers from the JavaCPP Presets of commonly used libraries by researchers. Eclipse OMR project is a set of open source C and C++ components. The Open Source Imaging Initiative (OSI) represents a new approach to the development of medical imaging devices. The Eclipse Deeplearning4J (DL4J) ecosystem is a set of projects intended to support all the needs of a JVM based deep learning application. MONAI is a PyTorch-based, open-source framework for deep learning in healthcare imaging. Open-source pipeline to create augmented reality (AR) models from scientific data. NVIDIA Clara Viz is a platform for visualization of 2D/3D medical imaging data. AlignTK is a toolkit designed for batch-oriented alignment of a large number of 2-D images in either 2 or 3-dimensions. Although it has been applied most extensively to electron-microscopy (EM) images of neural tissue, the package can be used with arbitrary grayscale images

The directory structure includes a specific folder for each phase of development and engineering programs:

- __MBSE__: The root folder Arcadia (ARChitecture Analysis and Design Integrated Approach) is a method of tools dedicated to systems engineering and architecture, supported by the Capella modeling tool.    
  - __CAD__: For computer-aided design.
  - __CAM__: Dedicated to the part manufacturing and assembly process.
  - __CAS__: For simulation of end-to-end functionality and performance analysis.
